## 🚀 Features

- **Modern & Responsive**: Fast, lightweight, mobile-first design with smooth interactions and micro-animations.
- **Light & Dark Mode**: Seamless theme switching with OS detection and local storage persistence.
- **Academic Sections**:
  - **About & Bio**: Overview of academic journey across William & Mary, NUS, UESTC, Cambricon, and SparcAI.
  - **News & Updates**: Latest milestones, awards, and paper acceptances.
  - **Research Focus**: Key research pillars (Deep RL, Speculative Decoding, VLA Models, 3D Simulation, MAPF).
  - **Selected Publications**: Filterable publication cards with venue badges, abstract summaries, and 1-click BibTeX copy.
  - **Experience & Timeline**: Research and industry experience timeline.
  - **Education & Honors**: Academic degrees, advisors, awards, and technical skills.
  - **Life & Photography**: Gallery showcase of outdoor passions and photography.

## 🛠️ Local Preview & Editing

To preview the website locally:

```bash
# Python 3 built-in HTTP server
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

---

## 📦 Deployment to GitHub Pages

This website is statically deployed to GitHub Pages. Any changes pushed to the `master` branch will be automatically updated on [https://ioet-y.github.io](https://ioet-y.github.io) within 1-2 minutes.

```bash
git add .
git commit -m "Update personal website"
git push origin master
```
